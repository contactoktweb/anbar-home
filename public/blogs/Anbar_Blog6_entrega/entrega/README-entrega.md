# Entrega — Blog 6 de Anbar Home

Esta entrega contiene el documento Word del artículo con las imágenes insertadas, las versiones WebP para publicación web, las imágenes PNG de alta calidad, la tabla SEO y las instrucciones de implementación.

## Archivos principales

- `Blog_6_SEO_Anbar_con_imagenes.docx`: documento final con el texto original del artículo, cuatro imágenes insertadas y sus pies de foto.
- `tabla-implementacion-imagenes.xlsx`: tabla editable para implementación.
- `tabla-implementacion-imagenes.csv`: versión compatible con otros sistemas.
- `instrucciones-keiner.md`: orden de carga, ubicaciones, ALT, pies de foto y recomendaciones técnicas.

## Carpetas de imágenes

- `../alta/`: versiones PNG de alta calidad.
- `../webp/`: versiones WebP preparadas para publicación web.

## Criterio de fidelidad

Las imágenes se crearon utilizando las fotografías suministradas por Anbar Home como referencias. Se conservaron los diseños, acabados, colores, texturas, bases, herrajes y proporciones visibles de los artículos. Los ajustes corresponden a integración ambiental, composición, encuadre, iluminación y eliminación de referencias comerciales, precios, etiquetas o textos de catálogo.

## Nota para publicación

Utilizar las versiones WebP en la página web y conservar las PNG como respaldo editorial. Las escenas funcionan como imágenes editoriales de ambientación para el artículo; no deben presentarse como fichas de producto individuales ni como fotografías documentales de un proyecto específico.

Las referencias y medidas de productos deben validarse contra el catálogo activo antes de utilizarlas como datos comerciales en la publicación.
