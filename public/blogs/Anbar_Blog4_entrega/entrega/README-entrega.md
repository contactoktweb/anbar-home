# Entrega — Blog 4 de Anbar Home

Esta carpeta contiene el documento Word del blog con las imágenes insertadas, la tabla de implementación SEO y las instrucciones para publicación web.

## Archivos principales

- `Blog_4_SEO_Anbar_con_imagenes.docx`: documento final con el cuerpo original del artículo, cuatro imágenes insertadas y pies de foto.
- `tabla-implementacion-imagenes.xlsx`: tabla editable para implementación.
- `tabla-implementacion-imagenes.csv`: versión compatible con otros sistemas.
- `instrucciones-keiner.md`: orden, ubicación, textos ALT, pies de foto y recomendaciones técnicas.

## Carpetas de imágenes

- `../alta/`: versiones PNG de alta calidad.
- `../webp/`: versiones WebP preparadas para publicación web.

## Criterio de fidelidad

Las piezas finales se compusieron a partir de las fotografías proporcionadas. Se conservaron los diseños, acabados, colores, texturas, bases, herrajes y proporciones visibles de los artículos. Los ajustes realizados corresponden a encuadre, composición, orientación, tamaño y conversión de formato.

## Nota para publicación

Utilizar las versiones WebP en la página web y conservar las PNG como respaldo. Las fotografías no deben presentarse como fichas de producto individuales; funcionan como imágenes editoriales de ambientación para acompañar el contenido informativo del blog.
