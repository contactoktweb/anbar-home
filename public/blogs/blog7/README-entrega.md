# Entrega — Blog 7 de Anbar Home

## Contenido del paquete

- `Blog_7_Como_elegir_jarrones_decorativos_FINAL.docx`: documento Word con el contenido, imágenes y enlaces.
- `blog-final.md`: versión Markdown lista para migración al CMS.
- `alta/`: cinco imágenes PNG de alta calidad.
- `webp/`: cinco imágenes optimizadas para publicación web.
- `tabla-implementacion-imagenes.xlsx`: tabla de carga para implementación.
- `tabla-implementacion-imagenes.csv`: versión CSV de la tabla.
- `instrucciones-keiner.md`: orden de implementación, enlaces, metadatos y validaciones.
- `auditoria-inicial.md`: diagnóstico del documento recibido.
- `keyword-map.md`: mapa de keyword principal y términos secundarios.
- `registro-no-repeticion.md`: registro básico de fotografías y composiciones usadas.
- `schema-blogposting-ejemplo.json`: schema sugerido para la publicación.

## Decisiones editoriales

- El artículo no incluye autor ni fecha.
- Se conservó el enfoque informativo y se amplió para público residencial y profesional en Colombia.
- Se utilizó una sola H1.
- Solo se incluyeron enlaces verificados de `anbarhome.co`.
- No se mencionaron nombres, referencias, materiales, medidas, precios ni disponibilidad de productos concretos.
- Las imágenes provienen de los dos diseños de Canva suministrados y confirmados como material de Anbar Home.

## Limitaciones

- El blog todavía no está publicado. La canonical corresponde a la ruta recomendada y debe confirmarse al crear la entrada.
- No se incluyeron métricas porque serán gestionadas por el analista.
- El manual de marca no estaba adjunto a esta entrega. El Word utiliza una presentación editorial neutra y las fotografías aprobadas.
- El schema no incluye fecha, autor ni URL de imagen porque esos datos deben definirse o generarse al publicar.
- Los enlaces de Canva incluidos en `instrucciones-keiner.md` conservan las composiciones editables para una nueva exportación desde las fuentes originales si el equipo la necesita.
